## Entry

**Recalled** — 8 characters, exactly one word.

The verdict: the ex was recalled, like a defective product pulled back by the manufacturer. One word, instantly readable as a verdict on a former partner, with a twist nobody sees coming.

## What the program does

`main.py` writes the single-word entry to `/output/entry.txt`. No network, no input, no secrets — it just writes the word, deterministically, every run.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Output: `Recalled`
